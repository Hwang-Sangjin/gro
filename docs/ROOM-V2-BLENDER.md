# Room v2 — Blender 수정 요청 (2026-10-28)

> Home 리디자인 새 시나리오에 맞춰 `grooves_room_blockout_reveal.glb` 를 고치기 위한 요청서입니다.
> 좌표·축은 **Blender 기준(Z-up)**. 웹(three)에서는 +Y up 으로 export 됩니다.
> 웹 테스트 페이지: `/lab/room-test` (`src/components/roomtest/RoomTest.jsx`)

## 0. 시나리오 (웹에서 이렇게 씀)

| 단계 | 화면 |
| --- | --- |
| 1 Hero | 크림 바탕 + 지금 Home 의 잉크 바이닐 판 |
| 2 | 스크롤하면 바탕이 **검은색**으로 바뀌고, 판이 **약 1/3 크기**로 작아짐 (카메라가 멀어짐) |
| 3 | 화면 가운데 아래에 **턴테이블만** 있고, 판이 그 위에 **내려앉음** |
| 4 | **턴테이블을 기점으로** 방이 만들어짐 → 램프가 하나씩 켜짐 → 창밖 **서울 야경**이 점점 보임. 턴테이블은 완성된 방의 오른쪽 벽에 있으므로 카메라가 왼쪽으로 옮겨 가며 방이 화면 가운데로 옴 |
| 5 | New Vinyls 섹션 → News 섹션 |

역할 분담은 그대로 **"어떻게 움직일지는 Blender, 언제 움직일지는 웹"** 입니다. 웹이 `pivot_*` 마다 움직이는 구간을 읽어서 턴테이블과의 거리 순으로 다시 배치하므로, Blender 타이밍은 미리보기용 기준이면 충분합니다.

## 1. 턴테이블 모델 (가장 먼저)

지금 `turntable` 은 면 6개짜리 박스(0.83 × 0.64 × 0.34 m)라, 판이 내려앉는 장면을 만들 수 없습니다.

- **실측 크기**: 본체 약 0.45 × 0.36 × 0.12 m, 플래터 지름 약 0.30 m (12" LP = 30.5 cm)
- **오브젝트를 나눠 이름 붙이기** (웹에서 이름으로 찾음)

| 이름 | 내용 | 원점(origin) |
| --- | --- | --- |
| `Turntable` | 루트 (빈 오브젝트 또는 본체) | 본체 바닥 중앙 |
| `Turntable_Plinth` | 본체 | — |
| `Turntable_Platter` | 플래터 (웹에서 33⅓로 돌림) | **스핀들 중심**, 회전축 = Z |
| `Turntable_Tonearm` | 톤암 | **톤암 회전 기둥 중심** (나중에 판 위로 내려오게) |
| `Turntable_DiscSeat` | Empty. 판이 앉을 자리 | **플래터 윗면 × 스핀들 중심** |

- **판(레코드)은 넣지 않기.** 판은 웹이 `vinyl.glb` 를 씀 (반지름 1 → 웹에서 0.15 m 로 줄임).
- **턴테이블에는 reveal 애니메이션 없음** — 방보다 먼저 혼자 화면에 있어야 해서 처음부터 scale 1. 등장은 웹이 처리.
- **따로 한 번 더 export**: `turntable.glb` (Lab Spin 3D, Vinyl A to Z #03 "Anatomy of a Turntable" 에 같이 씀).

## 2. 크기 (실제 미터)

지금 방은 약 7.5 × 9.5 m, 천장 4.6 m 라 서울 아파트 거실 한쪽치고 큽니다 (가구도 실제보다 약 1.5–2배).

- 바닥 **약 4.0 × 5.0 m**, 벽 높이 **2.3–2.4 m**
- 가구도 실측 (소파 폭 약 2.0 m, 콘솔 높이 약 0.5–0.6 m, 커피 테이블 약 1.0 m 등)
- 턴테이블은 콘솔 위, **오디오 벽(지금 `wall_audio` 쪽) = 최종 화면에서 오른쪽 벽**에 둠 (지금 위치 관계 유지)

## 3. reveal 애니메이션 다시 만들기 (수정이 가장 많음)

### 3-1. 기점을 바닥 → 턴테이블로

지금 바닥(`floor`)과 컷어웨이 테두리(`wall_cut_front`, `wall_cut_side`)는 애니메이션이 없어서, 웹에서 억지로 펼치고 있습니다. 모두 Blender에서 움직이게 해 주세요.

| 순서 (미리보기 기준) | 오브젝트 | 움직임 | pivot 위치 |
| --- | --- | --- | --- |
| 0.0–0.5s | `pivot_sideboard` (콘솔) | 바닥에서 위로 자라 올라와 공중의 턴테이블을 받침 (scale Z 0→1) | 콘솔 바닥 중앙 = 턴테이블 바로 아래 |
| 0.3–1.0s | `pivot_floor` (**새로**) | 턴테이블 아래 지점에서 바깥으로 펼쳐짐. 벽을 따라(X) 먼저 → 방 안쪽(Y)으로 | **턴테이블을 바닥에 투영한 점** |
| 0.8–1.3s | `pivot_wall_cut_front`, `pivot_wall_cut_side` (**새로**) | 바닥 테두리가 위로 솟음 (scale Z) | 각 테두리 바닥 |
| 0.8–1.4s | `pivot_wall_audio` | 턴테이블 뒤 벽이 경첩처럼 일어섬 (지금 방식 유지) | 벽 아래 모서리 |
| 1.2–1.8s | `pivot_wall_window` | 오디오 벽 모서리에서 창문 벽이 펼쳐짐 (지금 방식 유지) | 두 벽이 만나는 모서리 |
| 1.4–3.0s | 가구 (`pivot_speaker_*`, `pivot_amp`, `pivot_lamp_*`, `pivot_sofa` …) | 턴테이블에서 **가까운 것부터** | 각자 바닥 접점 (지금처럼) |
| 3.0–3.5s | 소품 (`pivot_plant_*`, `pivot_wall_art`, `pivot_cover_shelf_*`, `pivot_curtain`) | 마지막 | 지금처럼 |

> 바닥을 판자/타일 6–10장으로 나눠 각자 `pivot_floor_01…` 로 뒤집혀 깔리게 하면 "턴테이블에서 퍼진다"는 느낌이 더 살아납니다. 시간이 되면 이 방식, 아니면 위 표처럼 한 장 펼치기.

### 3-2. 키프레임 규칙

- **오브젝트 하나당 0.4–0.6초** (지금은 0.12초라 스크롤로 보면 툭툭 튐)
- 보간은 **Linear**, **오버슈트 없이** scale 0 → 1 (ease·오버슈트는 웹에서 넣음)
- 한 오브젝트의 키는 한 구간에만 (중간에 멈췄다 다시 움직이지 않기)
- **pivot 1개 = 움직이는 단위 1개.** 여러 가구를 한 pivot 에 묶지 않기 (웹이 따로 타이밍을 줌)
- 벽에 붙는 것(`wall_art`, 창가 `lamp_window`, `plant_03`, `curtain`)은 **해당 벽 pivot 의 자식**으로. 지금 `wall_art` 는 창문 벽 자식이 아니라 벽보다 먼저 허공에 뜸
- 러그 셰이프키(말림→펴짐)는 `pivot_rug` 이 커지는 구간과 **같은 시간**에 (지금은 0.08초에 한 번에 바뀜)
- 액션은 지금처럼 **`reveal` 하나**로 export

## 4. 창밖 서울 야경 (노을 → 밤으로 변경)

- `Window_City`: 창 밖에 놓는 평면 (또는 얕은 상자). **밤** 서울 — 짙은 남색 하늘, 아파트 단지 실루엣, 창마다 불빛
- 재질은 **Emission** 으로 (웹에서 세기를 0 → 1 로 올려 "점점 보이게" 함). 텍스처는 webp/KTX2, 2K 이하
- `Window_City` 는 `pivot_wall_window` 의 **자식** (창문 벽과 같이 펼쳐짐)
- 창은 실제로 뚫려 있게 (지금처럼). 유리를 넣으면 `Window_Glass` 로 이름 붙여 따로

## 5. 조명

- 램프 라이트는 Point 그대로, 이름을 `Light_Lamp_Floor`, `Light_Lamp_Table`, `Light_Lamp_Window` 로. 각 램프 pivot 의 자식 (지금처럼)
- 램프 갓 재질은 `Lamp_Shade` 하나로 (웹에서 Emission 을 올려 켜짐 표현)
- **조명에는 키프레임 넣지 않기** (켜지는 순서·세기는 웹)
- `light_key_window`, `light_fill` 같은 **Area / Sun 라이트는 glTF 로 나가지 않음** (빈 오브젝트로만 들어옴). 필요하면 나중에 bake 로. 블록아웃 단계에서는 지워도 됨
- 밤 장면이라 노을용 키 라이트는 불필요

## 6. 재질

- **모든 메시에 재질 하나씩** 넣어 주세요. 재질이 없으면 glTF 기본값이 metallic 1 이라 웹에서 새까맣게 나옴
- Principled: Metallic 0, Roughness 0.7–0.9. 블록아웃은 웜그레이·짙은 우드 2–4가지면 충분
- 재질 이름은 의미 있게 (`Wood_Dark`, `Wall`, `Fabric`, `Lamp_Shade` …)

## 7. 카메라

- 카메라 경로는 웹에서 만듦 → Blender 카메라 경로는 지금 필요 없음
- 대신 **최종 구도 참고용** `cam_room_final` 하나: 방 전체가 화면 가운데, 턴테이블이 오른쪽 벽에 보이는 각도 (지금 `cam_reference` 처럼 컷어웨이 모서리 쪽에서)
- `cam_old` 는 지우기

## 8. Export 설정

- glTF Binary (.glb), +Y Up, Apply Modifiers
- **Lighting Mode: Unitless** (지금은 Standard 라 W → cd 변환 때문에 웹에서 약 600배 밝음)
- Animation: `reveal` 포함, Shape Keys 포함, Punctual Lights 포함
- Compression: Draco (지오메트리)
- 파일 2개
  - `grooves_room_v2.glb` — 방 전체 (턴테이블 포함)
  - `turntable.glb` — 턴테이블만
- 목표 용량: 방 수 MB 이내
