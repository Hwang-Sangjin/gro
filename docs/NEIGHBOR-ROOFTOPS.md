# 이웃 옥상 3D 모델링 가이드 (좌우 전경)

이미지로는 방 원근(카메라가 18° 내려다봐서 화면 아래로 갈수록 가로선이 가팔라짐)을 맞출 수 없어서, 좌우 전경을 3D로 만든다.
자리는 env-test 에서 상자로 맞춰 봄: `/lab/env-test?nb=1&L.h_fg_l.on=0&L.h_fg_r.on=0` (설정 `env-layers.json` 의 `neighbors`).

- 배치도(위에서 본 Blender 좌표): `docs/env-test/nb_topview.jpg`
- 상자 배치 화면: `docs/env-test/nb_blockout.jpg`, 마우스 시차 양끝 `nb_blockout_l.jpg`, `nb_blockout_r.jpg`

## 좌표 기준 (Blender, m)

- 방 바닥 Z = 0, 방 바닥 범위 X −2.12 ~ +2.12, Y −2.65 ~ +2.63
  - 창문 벽 = X −2.12 쪽, 오디오 벽 = Y +2.63 쪽
- 방 아래 건물은 땅 Z −12.13 까지
- 카메라(B 18°): (11.8, −7.4, 5.7) 에서 방 가운데 (0.03, 0.09, 1.16) 를 봄, 세로 시야 17.2°
  - GLB 안의 카메라는 25°(A). 웹은 거리를 맞춘 18°(B)를 씀 → Blender 에서 확인할 땐 카메라를 위 위치로 옮겨서 보기

## 두 건물

| | 왼쪽 이웃 | 오른쪽 이웃 |
|---|---|---|
| 바닥 범위 (X, Y) | X −6 ~ +3, Y −9 ~ −3 | X +3.4 ~ +9, Y −0.5 ~ +7 |
| 옥상 바닥 높이 Z | +0.1 | −0.2 |
| 난간 | 높이 0.9m, 두께 0.18m, 네 변 | 같음 |
| 건물 몸통 | 땅(Z −12.13)까지 | 같음 |
| 화면에서 보이는 곳 | 왼쪽 아래: 가로 0~33%, 왼쪽 끝에서 높이 ~52%까지 | 오른쪽 아래: 가로 70~100%, 오른쪽 끝에서 높이 ~25%까지 |
| 실제로 보이는 옥상 바닥 | 안쪽 변(Y −3) 따라 X −8 ~ +3, 폭 약 2m (Y −3 ~ −5) | 안쪽 변(X +3.4) 따라 Y −0.5 ~ +7, 폭 약 1.3m (X +3.4 ~ +4.7) |
| 화면에 보이는 모서리 | (+3, −3) | (+3.4, −0.5) |

- 보이는 건 **카메라 쪽 모서리와 안쪽 변 근처 2m 띠뿐**. 나머지는 화면 밖이라 단순한 상자면 됨
- 시차 ×0.3 양끝에서도 위 범위 안 (궤도 ±3° 까지 크게 돌리면 더 드러남)
- 위치·높이는 상자로 맞춘 출발값. 모델링하면서 바꿔도 되고, 바뀐 값을 알려주면 `neighbors` 를 고쳐 다시 확인

## 꾸밀 것 (목표 이미지 기준)

- 옥상 바닥: 타일, 따뜻한 회색
- 난간: 낮은 콘크리트 벽(크림) + 그 위 가는 금속 난간
- 안쪽 변(보이는 띠)에: 화분·플랜터 2~3개 (잎 큰 식물), 벤치 하나(왼쪽), 랜턴
- 전구 줄: 난간 따라 늘어진 줄 + 둥근 전구 (지름 12~15cm, 발광 #ffc070). 가장 가까워서 크게 보임
- 외벽: 난간 아래 외벽에 불 켜진 창 한 줄 (발광 주황)
- 색: 외벽 크림(#e8d4bc) 또는 우리 건물과 맞춘 푸른 회색 중 선택, 그늘 짙은 보라
