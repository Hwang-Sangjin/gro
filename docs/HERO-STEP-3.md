# Hero 3단계: 카메라와 구도

직교 카메라를 유지하고 vinyl을 32도 기울인 뒤 화면에서 -25도 회전했습니다. Grooves 타이틀 중앙 뒤에서 위아래로 드러나는 대각선 타원 구도입니다.

`src/components/home/heroComposition.js`에서 각도와 화면 점유율을 조절합니다. 모델의 투영 타원과 두께를 기준으로 양쪽 축에 맞추므로 화면 회전과 리사이즈에도 잘리지 않습니다. 가로 화면 목표 너비 74%, 세로 화면 최대 90%, 높이 상한 72%이며 짧은 화면에서는 위아래 104px 여백을 우선 확보합니다. 세로/가로 비율 사이에서 연속적으로 보간합니다. 모델은 균일 배율을 사용해 기존 grooves 셰이더의 모델 좌표와 반지름 마스크를 유지합니다.

4단계 재질, 5단계 외곽선/그림자, 자동 회전과 마우스 효과는 아직 적용하지 않았습니다. 기존 GLB, 물리 재질, 홈 타이틀과 페이지 전환은 그대로 유지했습니다.

## 다음 4단계 제안 (미구현)

크림색 바탕과 푸른 잉크색의 해칭을 주재질로 만들고, 하프톤 점은 어두운 영역에만 약하게 추가합니다. 밝기에 따른 3~5단계 해칭 마스크를 부드럽게 섞고, 마스크를 모델 UV 또는 로컬 XZ에 고정해 모델 움직임에도 선이 미끄러지지 않게 합니다. 원형 grooves는 기존 반지름 계산을 활용해 불규칙하게 끊긴 가는 선으로 변환합니다. 기존 미분 기반 안티앨리어싱을 활용하며, 텍스처는 mipmap으로 축소 시 모아레를 줄입니다.

기존 anisotropy/groove 법선 계산을 유지하고, 그 명암을 손그림 톤으로 변환하는 별도 스타일 레이어를 설계합니다. 전체 화면 HalftonePass 대신 모델 재질에 적용해 HTML 타이틀과 UI를 선명하게 유지합니다. 외곽선과 접지 그림자는 5단계 범위입니다.

## 확인

프로덕션 빌드와 TypeScript 검사 통과. Chromium에서 1440×900, 390×844, 844×390 구도를 확인했습니다. 모델과 Draco 리소스를 로컬 경로로 불러옵니다. 화면 확인은 Supabase 앨범 응답을 빈 목록으로 대체했으므로 실제 데이터 연동은 이번 검증에 포함되지 않습니다. 외부 폰트 요청은 테스트에서 차단했으며 프로젝트의 로컬 Bodoni 글꼴로 확인했습니다.
